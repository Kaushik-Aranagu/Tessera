# Tessera

Tess for short. A personal "OS inside an app" for iPhone, built with SwiftUI, with a personality of its own so it can be a personal assistant. A tessera is a single mosaic tile: small blocks make apps, and apps make your own OS. App code is coming soon.

The old 2019 Simplenet experiments that used to live here are kept on the `archive/simplenet-2019` branch.
