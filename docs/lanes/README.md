# Lanes (Kaushik, Oct 22): three pillars, three lanes each

Design, coding and building each work three lanes: **UI/UX** (screens, motion, looks), **data and architecture**
(the store, Core, installs and gates), and **AI integration** (Tess, routes to Claude, on-device models). A lane is an
on-demand helper with its own short lessons note in this folder: what it learned and the mistakes not to repeat. Read
your lane's note before you start; add a line to it when you learn something the hard way.

Power-saver rules (Oct 22): new coding and merge helpers run on Sonnet; gates, test runs, installs and release cuts on
Haiku; a failure that needs diagnosing goes to Sonnet. At most three helpers at once, only for lanes with queued work.
From 11 PM to 7 AM only gates and installs run. Helpers never post to the project thread and never touch the release
gate scripts or the Tessera builds folder.
