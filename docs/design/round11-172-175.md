# Items 172 to 175: Round 11, add a spend, repeats, note to tasks, haptics (Oct 23)

Loop round 11 (10-minute cadence, power saver). Lane named per item. Each behind its own Review
switch, default Off (175 is a rule sheet). Grammar from 127 and 131. Money stays on the phone.

## 172 Add a spend as a sentence (lane: UI and UX, switch moneyAddV2, Builder B)
Money's add line is one editable sentence: "12 at Trader Joe's, from US checking."
- Words are fields: tap "12" for the amount (Outfit, digits roll), "Trader Joe's" for the place
  (recent places as plain words), "US checking" for the pool (Money-green underline).
- Currency follows the pool. A foreign pool shows "about 13 US" in ink 2 under, never inline.
- Done = a plain word "Add". The Home receipt shows no amount ("Lemons, from US checking.").
- Never offered to Claude; the sentence is parsed on the phone.

## 173 Repeats (lane: data and architecture, switch repeatsV2, Core)
One recurrence model for tasks, bills, routines and meals, written as a sentence.
- Field Repeats on any dated object: "Every month on the 1st", "Every other Friday", "Every 3
  days after done". Stored as a rule, not as copies; the next date is computed.
- Skipping one is an op ("Skip this one"), undoable. Ending is "Stop repeating".
- Pages show it as a plain ink-2 line under the title. Quiet and Focus respect it unchanged.
- Rent shows "Rent, Friday" and never an amount on Home.

## 174 Note to tasks (lane: AI, switch noteTasksV2, Core with Builder B)
On a note, lines that look like to-dos get a cobalt offer from Tess, on the phone only.
- "3 look like tasks." with "Make them" and "Not now". Make them creates Tasks linked back to
  the note (backlink "Mentioned in"). Undo for 10 min (164).
- Foundation Models classifies lines on-device; walled or private notes never get the offer.
- Never reaches Claude. One offer per note per day.

## 175 One haptic vocabulary (lane: UI and UX, rule sheet, all builders)
Three feels, used the same everywhere. One haptic per moment; Reduce Motion does not remove them.
- Tick (selection): scrubbing, picking, reordering slots.
- Soft: a thing lands or is marked (strike, check-off, Keep).
- Rigid: a thing finishes (last set, served, shutdown).
- Undo and errors use the same soft, never a warning buzz. Audit list in each PR.
