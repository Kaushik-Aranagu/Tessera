## 164 Undo from the op log (lane: data and architecture, switch undoLogV2, Core)
Every change already writes an OpRecord. One Undo for anything changed in the last 10 minutes.
- After a change the foot of the page says what happened in plain words ("Moved Limes to To get.")
  and "Undo" in vermilion underline. Tap restores from the op, and the line becomes "Put back."
- Undo reverses one op or one batch (a shop, a finished workout). Never partial.
- Walls hold: undoing never resurrects a purged private item. Money moves undo as a reverse op,
  not a delete, so the pool history stays honest.
- Settings > Review > "Recent changes" lists the last 20 ops as sentences, each with Undo.

## 165 Lists v2 (lane: UI and UX, switch listsV2, Builder B)
A list is a page of plain lines under a sentence: "Trip packing, 6 left."
- Check off with a swipe right: strike follows the finger, soft tap. The count rolls (HouseNumber).
- Lists accent underline (5E6B1F/B5BE7A) on the list name only. Done items sink to "Done, 12"
  collapsed under a plain word; tap opens.
- A list can be shared into a day: "Add to Saturday" makes a Now item with the left count.
- Empty list uses 163's sentence.

## 166 Ask this page (lane: AI, switch askPageV2, Core with Builder A)

## 167 Quiet hours (lane: data and UI, switch quietHoursV2, Core with Builder B)
Settings > Quiet: when notices wait (QuietInterrupts).
- A sentence: "Quiet 10 pm to 7 am. 2 things are waiting." Edit by dragging two ends on a line
  that spans the day; digits roll, a tick at each hour.
- Exceptions as plain words ("Timers", "Gym"). Focus (156) turns Quiet on by itself; it ends
  with the digest.
- House clock always am/pm.
