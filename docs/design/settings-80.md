## Copy rules the sheet follows
Digits for counts; no "…"; no "at" before a time ("9:05 am", "6:12 pm"); " · " nowhere; cobalt is Tess's voice only; "Private note" is the only name of a private note; no model name, no key text or key-shaped string in any fixture ("...a1B2" is the existing mask); a failed call still counts (see below).
