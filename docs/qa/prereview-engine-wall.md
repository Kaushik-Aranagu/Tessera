## Findings
- **W1 (medium, wrong weight source).** `BodyWeight.kilograms(in:)` takes the FIRST number of the newest private note that is body-shaped, and accepts anything in 25...300. A newer private note "bp 120/80", "ibuprofen 200 mg" or "hr 65" is body-shaped (vital or medicine), so `lastKg` becomes 120, 200 or 65, and then every bare number within 10% of that is walled ("is 125 good?") while his real weight stops matching. Fix: only take a number that has a weight unit (kg/lb/kilos/pounds) or a weigh word beside it, or `bare number + weigh word`; drop the `isBodyShaped` escape in the guard. Add tests: newest note "bp 120/80" does not change lastKg.
- **W2 (medium, cost).** `BodyWeight.lastKg` scans every private note, sorts, and runs regexes on each call, and `ObjectPrivacy.label` now calls it for every row (Notes list, Linked from, refs, Review). With years of notes this is O(rows x private notes). Cache it per store change (an op-count or `updatedAt` key) or compute once per list render and pass it in; ScaleTests (dayLogStaysFast already flaked under load once) should cover a 5-year history.
- **W3 (low, over-wall).** A bare number within 10% of his weight is walled anywhere in a title ("Room 82", "Gate 84", "Pick up 80 flyers" unless a listed unit follows). It turns a task into a private note silently. Product accepted the 10% rule at 4:46 PM; consider requiring a decimal or a weigh/body word unless the line is only the number ("82.4", "is 82 good?"), and make the Tess reply say the note was kept private.
- **W4 (low, mismatch).** TessCaptureEngine.swift:297-300: for "Pay rent 2100 fri" `isPrivateTitle` is true (money-shaped) so Tess says the private-task line, but EngineWall stored the plain "Pay rent fri" task. Safe direction, wrong words. Use the stored outcome (or `EngineWall.task`) to pick the reply.
- **W5 (low, doc/behavior).** EngineWall's header says his own words in his own place (Notes page, "note:") are exempt, but CreateNote.apply now forces private for any money- or body-shaped text from any actor (Notes.swift isPrivateText). A note he types "ran 5 km, 82 kg" becomes "Private note". That matches the #580 mask and Product's rule, so confirm it is intended and fix the comment, or add an actor/source exemption.
- **W6 (low, tests).** Cover: CreateTask whose outcome is a note still gets a receipt (OpRecord.receipt "Private note, kept"); AddListItem "milk $4" -> "Milk" and "$40" -> private note; `kept` and `apply` agree for 10 sample lines (they are two copies of the same logic, drift risk; make apply use `kept`).
