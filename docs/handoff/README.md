## Restore the repo
Clone the repo (fetching is fine), go to the base commit, and pull the local commits from the bundle:
```bash
git clone https://github.com/Kaushik-Aranagu/Tessera.git
cd Tessera
git checkout -b design 0061df0
git pull --ff-only ../tessera-local-commits.bundle master
git log --oneline -3
```
The tip is `b22a55b`. The design lives under `docs/handoff/`, identical to the `handoff/` folder here, so you can also
skip git and work from `handoff/` directly.

**Do not push this to GitHub.** The owner asked that nothing from this work be pushed, PR'd, or commented on GitHub. Work locally.

## Open the boards
Each board and the prototype is a single HTML file. Open it in any browser:
```bash
open handoff/design-sheets/prototype/index.html
```
Boards scale the 402x874 phones to fit the window. Useful query params (where a board supports them): `?hour=17`, `?weather=rain`, `?demo=1`, `?ix=2`, `?instant=1`.

## Render screenshots headlessly
`handoff/session-oct25/scripts/shot.sh` wraps headless Chromium:
```bash
chrome --headless=new --no-sandbox --disable-gpu --hide-scrollbars --force-device-scale-factor=2 --window-size=1300,1100 --virtual-time-budget=6000 --screenshot=out.png "file:///abs/path/board.html"
```
- Use `--dump-dom` to read state written to the DOM or `document.title`.
- In the prototype, open a screen directly with `reset('notes')`; `go()` slides it in and a shot taken mid-slide looks clipped.
- The Watch woodland hangs Chromium under `--virtual-time-budget`. Shoot it in real time: `REAL=1 shot.sh board.html out.png`.
- After changing the 268 or 278 board, regenerate the prototype's copy: `python3 handoff/session-oct25/scripts/make_embed.py handoff/design-sheets/money-indices-278/board.html handoff/design-sheets/prototype/purse.html` (and the same for 268 into `watch.html`). Section 6.5a of `TESSERA-DESIGN.md` explains why.
- `jscheck.sh` syntax-checks every script block in a board.
- `TESSERA-DESIGN.md` has the full rendering guide: canvas DPR, the one rAF loop, eased values, the edge dissolve, plates.
