In Tessera, the keystone slot is one fixed size on every landing: 354 x 182 pt at top 196 (the Home mosaic's slot). Home, Notes, Routines, Weather, Kitchen, Training all use it. When a keystone has more to show than fits (the Kitchen pass's tickets), it pages inside the slot (flip up / flip down); the band is never made taller.

**Why:** Kaushik's correction on Oct 25, 2026 after the Kitchen pass board grew the band: "whatever the size of the centerpiece is, it should be the same across all the apps... that's why we flip."
**How to apply:** Design every keystone to the standard slot first; add pages, not pixels. Approved keystones so far: Home mosaic, Notes word wall, Routines woodland (pending verdict), Weather skypiece (surface approved), Training blackboard (locked), Kitchen pass (decided).
