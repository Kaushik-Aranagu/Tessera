## 1. Rules to keep

- Install only gate-green heads: `scripts/test.sh` all green (package, app, watch) plus a Release device build of that exact SHA. Standing yes from Kaushik: install coordinator-named releases without waiting. Step 0 first: `~/Library/Developer/TesseraBuilds/release-install.sh <sha7> <from-sha7>` copies the phone's data (integrity-checked, write-protected, never deleted) and then installs in place. Never install over a running Tessera if you can avoid it.
- Kaushik (Oct 24): the phone runs on SAMPLE data until he says production ready. His current data does not need saving, and the app opens on the sample store by default.
- Every build, test and install goes through `scripts/ops/mac_lanes.sh` (up to 3 slots, own DerivedData and simulator per slot, a device lock for installs, a disk guard). `~/Library/Developer/TesseraBuilds/lane_lock.sh` is the old lock: do not mix. The Mac is small (10 cores, 24 GB): never run parallel builds outside the slots, kill processes by PID only, delete only finished worktrees' `.build` and DerivedData.
- After a branch switch or inside a release `src-<sha7>` run `xcodegen generate` before a gate (a missing generate once failed a gate).
- Never run `defaults write review.*` on a simulator you use for gates.
- UI equals backend in weight. No stock or card UI. Every approved design lands exactly like its sheet (sizes, fonts, colours). All visuals through Theme tokens and `ThemeConcept`; animate only through `MotionPolicy`; Reduce Motion, Reduce Transparency, Low Power and Dynamic Type respected.
- Pixel art only on the Home mosaic. No decorative underlines anywhere. No glass lens (cancelled). Big type never shares one colour (rule below).
- Display lines fit their slot: no wrap, no push or shift on live change, never a smaller font or "..." (input fields exempt).
- Walls: never show money amounts, health, body or calories on Home or in widgets; private items use `ObjectPrivacy.shownLabel`; calendar text stays on the phone; place kind is never stored, logged or backed up; speech on-device only; only Tess takes touches on her layer.
- Gesture rule: a plain tap must reach row buttons. A `highPriorityGesture` of LongPress sequenced before Drag(0) swallowed apps-list taps (fixed by #1392). Always add a UI tap test with every gesture.
- Never resolve another author's merge conflicts: send each back to its author. Commit trailer `Co-Authored-By: ...`; PR bodies start with the attribution block (see CODEX.md). Run `swiftformat .` and `swiftlint`; revert collateral edits (it touches `Features/Backup/BackupKeeper.swift`).
