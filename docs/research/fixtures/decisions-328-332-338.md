## Part 2. Ruling 5:40 stamp G94 plus 3:43 PM: the quantity rule

There are two different places a leading number is read on master, and the ruling reaches only one of them. Rows are split accordingly.

### 2.1 What exists on master

**Paste title rule (what G94 and 3:43 PM change).** `RecipeParser.classify` (`TesseraCore/Sources/TesseraCore/Kitchen/RecipeParser.swift:41-70`): line index 0 is the title when `!startsWithAmount(line)` and `!isSentence(line)` (`:53`). `startsWithAmount` (`:171-175`) is true when the first character is a number (`clean.first?.isNumber`) or the line opens "a/an" plus pinch, handful, bunch, clove, can, tin, slice, sprig. So today **any** first line that opens with a digit is "Untitled recipe", including "30-Minute Dal", "7 Layer Dip", "5-Ingredient Chili", "3 Eggs Benedict". The doc comment on `isSentence` (`:72-73`) says "does not start with a quantity" but the quantity check lives in `startsWithAmount`. `isSentence` (`:74-77`) is: ends in ".", "!" or "?", or more than 12 words. `parse` falls back to "Untitled recipe" at `:116`, and the first line then classifies as ingredient or step (`:55-66`; `looksLikeIngredient` `:155-169`).
Existing test: `RecipeTests.swift:123-143` (`theTitleRule`): `"2 eggs"`, `"1/2 cup flour"` and `"A pinch of salt"` first give "Untitled recipe" (`:140-142`).

**Written-out amounts (G95, stays as is).** `startsWithAmount` does not read words; "two dozen eggs" as a first line has no leading digit, so it is a title today. `IngredientLine.parse` (`Kitchen/Quantities.swift:135-`) reads "a"/"an" plus a unit word (`:159-162`) and digits (`:163-165`); the comment at `:159` mentions "one" but only "a" and "an" are matched.

**List item path (not changed by G94).** `AddListItem.apply` (`Lists/Lists.swift:182-210`) stores the typed text as the item title, and `quantity` only when the caller passes it (`:197-199`); no code splits "2 eggs" into quantity and name. `AddListItem.kept` (`:213-237`) runs `EngineWall.withoutPrice` (`Tess/EngineWall.swift:71-84`, takes off "$4", "4 dollars", and a bare two-place decimal at the end or before at/for/from/on), a measure exemption (`:217-227`: "1.25 cups flour"), `isAmountOfAThing` (`:240-264`: a number, a weight/volume unit, then a food word: "1.50 lb apples", "2 kg rice"), then private-note rules (`isSumOnly` `:268-278`, `isBareWeight` `PrivateFacts.swift:161-`). Result: the item keeps the typed text minus the price. The grammar for "buy"/"groceries" lines is `TessGrammar+Kitchen.swift:43-66`; its comma-list reader uses `IngredientLine.parse` to decide a line is shopping (`:91-98`).
