## How to grade

Mark exactly one of Pass or Fail per row with an x, and put file:line evidence in Notes. Pass: the code and the named test match the Expected column. Fail: the code, the test or the text differs, or the test name is missing. A row left blank is not graded. Rows marked inferred (G179) were not read against master: read them first. The grep helper `g` and the base SHA steps are in the walk script, "Before you start".
