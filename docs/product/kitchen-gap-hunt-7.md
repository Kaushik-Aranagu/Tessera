**Probes tried and dropped as already covered or not a gap.** Deleting the built-in Groceries list (G6, G29). A list that Groceries links to: no list is ever the target of an `about` link (rows link ingredients and recipes), so there is nothing to orphan. A Private item moved between lists: no action reparents an item (`MoveListItem` moves within one list, `Lists.swift:249-266`); the section move is G41. Clear-done with a Private item on the list: `clearDone` (`Lists.swift:349-358`) soft-deletes every checked row and the receipt names only the list, so no word leaks. A recipe renamed after its cook: the line takes the current title, which is true; the title length is G50. Relaunch mid-shop: the process persists, so a normal relaunch keeps the shop; the abandoned one is G44. Dynamic Type on Pantry: #739 put the state word under the name at accessibility sizes (`PantryView.swift:180-197`); nothing new found. Empty clear (G15), duplicate-name create receipt and "no open-the-existing-list" (FG5), walled export (G28, G36, G37).

**House rules used by every row.** Receipts name the thing first and use "on" ("Milk, on Groceries."). No "at" before a time. Clocks are lowercase ("8:30 pm"). Digits for counts. US English. A walled thing reads "Private item", "Private recipe" or "Private note". On-screen counts keep private things and hide their names (decisions 3:25 #1). No row, fixture or log contains a key or a key-shaped string.
